# 空位检测与 3D 定位、推荐放入位置 PPT 思路

主题：从“柜内空白区域”到“机器人可执行的放置坐标”

建议页数：3 页。如果 PPT 总页数紧张，可以压缩为 2 页：第 1 页讲空位检测与 3D 定位，第 2 页讲推荐策略和交互结果。

## 第 1 页：空位检测：从物体占用到候选空位

建议标题：空位检测：在每一层中寻找真实可用区域

### 页面核心内容

空位检测不是简单找 RGB 图像中的“空白”，而是在每个层板区域内建立占用模型：

```text
输入：Shelf 层区域 + 已知物体框 + 未知障碍框
        ↓
物体/障碍框安全膨胀
        ↓
投影到当前层的横向占用列
        ↓
扫描连续空闲列
        ↓
结合物理尺寸阈值筛选 Empty Space
```

### 讲解重点

1. **以层板为单位检测空位**

   系统先获得每一层 `Shelf box`，再在每层内部单独判断占用和空闲。这样可以避免不同层之间互相干扰，例如上层物体不会影响下层空位。

2. **已知物体和未知障碍都参与占用**

   绿色框物体和灰色未知障碍都会被视为不可放置区域。未知物体虽然没有四类语义标签，但仍然有物理位置，必须参与避障。

3. **安全膨胀提升鲁棒性**

   每个物体/障碍框会向外膨胀一定像素，留出安全余量，补偿检测框误差、深度误差和机械臂放置误差。

4. **横向占用列模型**

   对于每一层，系统把物体框投影到横向列：

   - 被物体或障碍覆盖的列标记为占用。
   - 连续未占用的列标记为候选空闲区域。
   - 连续宽度不足的区域被过滤。

### 图占位建议

- 左侧：`annotated.png` 中某一层的物体框、障碍框和蓝色空位框。
- 右侧：自画一个简化示意图：

```text
Shelf 2:
| 空闲 | 物体占用 | 空闲 | 障碍占用 | 空闲 |
  蓝       绿        蓝       灰        蓝
```

或用条形图表示：

```text

[ 空 ][ 空 ][ 占 ][ 占 ][ 空 ][ 空 ][ 空 ][ 占 ][ 空 ]
```

### 可放到 PPT 的短句

- 空位检测以层板为单位进行，避免跨层干扰。
- 已知物体和未知障碍共同参与占用建模。
- 通过安全膨胀和连续空闲列扫描，提高真实放置场景下的鲁棒性。

## 第 2 页：3D 定位：从像素空位到真实空间坐标

建议标题：3D 定位：将空位转换为相机坐标系下的放置点

### 页面核心内容

系统利用 RealSense 深度和相机内参，把 2D 像素位置转换为 3D 坐标：

```text
X = (u - ppx) * Z / fx
Y = (v - ppy) * Z / fy
Z = depth(u, v)
```

其中：

- `u, v`：图像像素坐标。
- `Z`：该层或物体对应的深度。
- `fx, fy, ppx, ppy`：相机内参。

### 讲解重点

1. **物体 3D 坐标**

   对已识别物体，系统在检测框内取有效深度中值作为 `Z`，再计算：

   - `center_m`：物体框中心三维坐标。
   - `contact_center_m`：物体框底边中心三维坐标，更接近物体与层板接触点。

   这样既能知道物体在图像中的位置，也能知道它在相机坐标系中的真实位置。

2. **空位 3D 坐标**

   对空位，系统用空位框中心像素作为 `(u, v)`，用该层 `median_depth_m` 作为深度 `Z`，反投影得到空位中心：

```text
EmptySpace.center_m = (X, Y, Z)
```

3. **物理尺寸约束**

   空位是否足够大，不按固定像素判断，而是根据深度换算成真实尺寸：

```text
space_width_m  = pixel_width  * Z / fx
space_height_m = pixel_height * Z / fy
```

   同样宽度的像素区域，在远处和近处代表的真实尺寸不同，所以必须结合深度判断。

4. **为什么用层板代表深度**

   空位本身没有物体，不能像物体那样从框内取前景深度。系统使用当前层板的代表深度 `median_depth_m`，近似表示放置面到相机的距离，从而得到可用于放置的中心坐标。

### 图占位建议

- 左：针孔相机反投影公式示意图。
- 中：`top_view.png` 中推荐空位位置。
- 右：`result.json` 中空位坐标摘录，例如：

```json
"center_m": [-0.166, -0.398, 1.710],
"size_m": [0.389, 0.395, 0.080]
```

### 可放到 PPT 的短句

- 2D 框负责定位图像区域，Depth 和相机内参负责恢复真实坐标。
- 空位尺寸由像素宽高、深度和焦距共同决定。
- 输出的 `(X, Y, Z)` 可作为后续机械臂放置规划的空间锚点。

## 第 3 页：推荐放入位置：从候选空位到可解释决策

建议标题：推荐放入位置：同类优先、尺寸约束、结果可解释

### 页面核心内容

推荐模块在空位检测结果上进一步结合新物体任务输入：

```text
输入：新物体类别 + 新物体尺寸 + 候选空位 + 已有物体 3D 坐标
        ↓
过滤放不下的空位
        ↓
计算每个空位得分
        ↓
输出推荐层号、空位框、中心 3D 坐标和推荐理由
```

### 讲解重点

1. **先按尺寸过滤**

   用户输入新物体尺寸：

```text
width, height, depth
```

   系统要求候选空位满足：

```text
space_width_m  >= item_width_m  + safety_margin
space_height_m >= item_height_m + safety_margin
```

   尺寸不满足的空位直接排除。

2. **再按类别和距离评分**

   如果柜内存在同类物体，推荐更靠近同类物体的空位：

```text
score = 空位面积得分
      + 同类物体加分
      + 同层加分
      - 到最近同类物体的 3D 距离惩罚
```

   如果没有同类物体，则优先选择面积更大的安全空位。

3. **同层加分**

   若空位和已有同类物体在同一层，系统额外加分，使推荐更符合人类整理习惯：同类物品尽量放在一起，同层优先。

4. **推荐结果可解释**

   输出不仅包含推荐位置，还包含理由，例如：

```text
Near existing Breakfast object; distance 0.948 m.
Same shelf is preferred.
```

5. **人机交互衔接**

   Web 界面中可以先运行一次检测，再修改新物体类别和尺寸。系统不重新跑 Grounding DINO，只基于已有空位快速更新推荐，适合展示不同任务输入下推荐结果的变化。

### 图占位建议

- 左：Web UI 中“放入新物体”输入区域。
- 中：`annotated.png` 中金色推荐框。
- 右：推荐结果卡片，包含：

```text
新物体：Breakfast
推荐层：Shelf 1
中心坐标：(-0.166, -0.398, 1.710) m
理由：靠近已有 Breakfast 类物体，且空位尺寸满足要求
```

### 可放到 PPT 的短句

- 推荐不是只找最大空位，而是结合类别、尺寸、距离和同层关系。
- 新物体尺寸改变时，候选空位会动态减少或变化。
- 新物体类别改变时，同类锚点改变，推荐位置也会改变。

## 这一部分的讲述主线

这一节可以用一句话串起来：

系统先在每层建立占用模型，找出满足真实尺寸的候选空位；再利用深度和相机内参把空位转成 3D 坐标；最后结合用户输入的新物体类别和尺寸，在候选空位中选择最符合整理规则的放置位置。
