# 5 分钟课程汇报 PPT 规划

主题：面向泛化性与鲁棒性的多层柜体 RGB-D 感知与交互系统  
建议页数：6 页  
总时长：约 5 分钟  
主线：按任务链路展开，分为感知层面和人机交互层面。感知层面强调每个任务中提升泛化性与鲁棒性的设计；人机交互层面强调用户如何参与调整、验证和推荐。

## 第 1 页：任务背景与系统主线

建议标题：多层柜体物品识别：从开放词汇感知到交互式放置推荐

预计时间：35 秒

页面内容：

- 任务场景：服务机器人面对无门多层柜，需要理解柜内物品、层板、空位和三维坐标。
- 难点：
  - 物品类别和外观不固定。
  - 柜体位置、层高、拍摄角度可能变化。
  - 深度图存在噪声、空洞和遮挡。
  - 未知物体不能强行分类，但必须避障。
- 系统主线：
  - 感知层面：数据采集、开放词汇识别、柜层识别、空位识别与 3D 定位。
  - 人机交互层面：Web 可视化、ROI 调整、参数调节、新物体推荐。

讲稿要点：

这个实验的核心目标是让机器人在真实柜体环境中具备更强的泛化和鲁棒能力。我的系统不是针对固定图片写死规则，而是把开放词汇语义识别、RGB-D 几何和交互式参数调整结合起来，让它适应不同物品、不同柜体和不同任务输入。

图占位：

- 放最终 `annotated.png`。
- 角落放颜色图例：绿色=物体，红色=层板，蓝色=空位，灰色=未知障碍，金色=推荐。

## 第 2 页：任务链路总览

建议标题：系统流程：按任务逐步增强泛化性与鲁棒性

预计时间：40 秒

页面内容：

```text
数据采集
  RealSense RGB-D 对齐 / session / replay
        ↓
开放词汇语义识别
  Grounding DINO + yml 候选词表 + unknown prompts
        ↓
柜体 ROI 与后处理
  自动/手动/多边形 ROI + 去重 + 宽框拆分
        ↓
柜层识别
  ROI 点云 + 体素降采样 + 水平平面带 + RGB-D 边缘兜底
        ↓
空位识别与 3D 定位
  占用投影 + 物理尺寸约束 + 相机内参反投影
        ↓
人机交互
  Web 可视化 + 新物体类别/尺寸 + 两阶段推荐
```

讲稿要点：

我按照任务链路来组织系统。前半部分是感知：先获得可靠 RGB-D，再识别物体和未知障碍，然后识别层板和空位并输出三维坐标。后半部分是交互：用户可以通过界面调整 ROI、候选类别、新物体尺寸和推荐参数。

图占位：

- 一张纵向或横向流程图。
- 右侧三联图：原图/识别图、俯视图、3D 地图。

## 第 3 页：感知任务一：数据采集与开放词汇语义识别

建议标题：感知一：让系统适应不同物品

预计时间：55 秒

页面内容：

数据采集：

- RealSense 彩色流 + 深度流。
- 深度对齐到彩色图。
- 保存 `color.png`、`depth.png`、`intrinsics.json`。
- 多帧中值融合和深度补洞降低噪声。

开放词汇识别：

- Grounding DINO，不使用闭集检测器。
- yml 中配置四类候选词：
  - Cutlery：fork、knife、spoon...
  - Tableware：cup、mug、plate...
  - Breakfast：cereal、bread、yogurt...
  - Soft Drink：cola、soda、beverage bottle...
- 可手动在 yml 里添加候选词、品牌词、同义词。
- unknown prompts 保留未知障碍。
- 类别独立阈值减少误检/漏检。

讲稿要点：

语义识别的泛化性主要来自开放词汇。系统不是只检测四个抽象类别，而是在 yml 中为每类维护具体候选词表。比如杯、碗、盘都可以归入 Tableware，如果场景里出现新的具体物品，只需要在 yml 里加词，不需要重新训练模型。未知物体通过 unknown prompts 保留为障碍，不参与四类统计但参与避障。

图占位：

- 左侧放 yml prompt 片段。
- 右侧放绿色物体框和灰色未知障碍框。
- 可放一张深度图小图说明 RGB-D 输入。

## 第 4 页：感知任务二：柜层识别

建议标题：感知二：用点云几何适应不同柜体结构

预计时间：1 分 5 秒

页面内容：

柜层识别流程：

```text
柜体 ROI 内有效深度点
→ 反投影为 3D 点云
→ 体素降采样
→ 按相机竖直方向 Y 分箱
→ 寻找点数多、横向覆盖宽的水平平面带
→ 合并相邻候选带
→ ROI 顶/底边 + 内部分界线生成层区域
→ RGB-D 水平边缘兜底
```

鲁棒设计：

- ROI 限制柜内区域，避免背景参与层板识别。
- 点云水平带适应非等高层板。
- RGB-D 边缘兜底处理深度缺失。
- yml 可配置层数、层边界、最小层高和边缘搜索范围。
- 单层约束过滤跨层物体框。

讲稿要点：

层板不是简单把图像等分。系统先把 ROI 内深度点反投影成点云，再按竖直方向找横向覆盖很宽的水平点带。真实层板在某个高度会形成长条支撑，而普通物体通常只占局部。点云候选不足时，再用 RGB 行梯度寻找水平边缘作为兜底。

图占位：

- `startup_roi.png`：ROI。
- `map_3d.png`：点云。
- 一张简化示意：按 Y 分箱，峰值对应层板边界。
- `annotated.png` 中红色层板框。

## 第 5 页：感知任务三：空位识别与 3D 定位

建议标题：感知三：从图像空白到真实可放空间

预计时间：1 分

页面内容：

3D 反投影：

```text
X = (u - ppx) * Z / fx
Y = (v - ppy) * Z / fy
Z = depth(u,v)
```

空位识别：

```text
每层 Shelf 区域
→ 已知物体和未知障碍框膨胀
→ 投影成层内占用列
→ 扫描连续空闲列
→ 物理尺寸换算：min_px = size_m * f / Z
→ 输出 EmptySpace 的框、真实尺寸和 3D 中心
```

鲁棒设计：

- 未知障碍与已知物体共同参与占用。
- 安全膨胀避免贴边。
- 物理尺寸约束避免只按像素判断。
- 最终再次切分空位，避免空位覆盖已显示物体。

讲稿要点：

空位不能只看图像上有没有空白，而要判断真实宽高是否足够。系统把每层压成横向占用模型，物体和未知障碍都会占用一定列。连续空闲列足够宽，并且换算到真实尺寸后满足要求，才被输出为空位。物体和空位的三维坐标都由深度和相机内参反投影得到。

图占位：

- `top_view.png`：占用与空位。
- 一张占用列示意图。
- `result.json` 中空位坐标摘录。

## 第 6 页：人机交互层面：可调整、可验证、可推荐

建议标题：人机交互：让用户参与感知修正与放置决策

预计时间：45 秒

页面内容：

Web 界面：

- 左侧：选择 session、检测器、自动 ROI、Unknown 障碍、手动 ROI。
- 中央：识别结果、俯视图、3D 地图、原图、深度图。
- 右侧：物体/层板/空位/障碍数量、推荐结果、物体列表。

两阶段交互：

```text
重新检测当前图片
→ 保存物体、层板、空位、点云结果
→ 输入新物体类别和尺寸
→ 不重跑大模型，快速更新推荐
```

推荐策略：

```text
score = 空位面积
      + 同类物体加分
      + 同层加分
      - 到最近同类物体的距离惩罚
```

讲稿要点：

交互层面主要解决现场可调和结果可解释。用户可以手动框 ROI，决定是否使用 Unknown 障碍，也可以输入新物体类别和尺寸。系统先完成一次感知检测，后续修改新物体参数时只重新做空位过滤和推荐，因此适合快速演示不同任务输入下的推荐变化。

图占位：

- Web UI 截图。
- 推荐结果卡片。
- 金色推荐框局部。
- 示例：`Breakfast -> Shelf 1, center=(-0.166,-0.398,1.710)m`。
