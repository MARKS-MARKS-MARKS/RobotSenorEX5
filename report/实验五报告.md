# 实验五：多层柜子中的物品类别识别

## 1. 实验目的

本实验面向服务机器人日常物品整理场景，使用 Intel RealSense D435 获取对齐后的 RGB-D 数据，在多层无门柜子中完成已有物品的开放词汇语义识别、柜层空间结构提取、可用空位检测和三维坐标输出，为机械臂后续将新物品放到同类或相似物品旁边提供感知依据。

## 2. 系统方法

系统由四个模块组成：

1. RGB-D 采集模块：使用 RealSense SDK 同步并对齐彩色图和深度图，保存 `color.png`、`depth.png` 和 `intrinsics.json`，保证二维像素与深度一一对应。
2. 开放词汇识别模块：采用 Grounding DINO 零样本检测，通过提示词识别 `Cutlery`、`Tableware`、`Breakfast`、`Soft Drink` 四类物品，并在 RGB 图像中绘制绿色边界框、类别和置信度。
3. 三维几何模块：根据相机内参将深度反投影到相机坐标系，结合水平边缘、深度突变、有效深度区域和占用区域估计柜层；通过物品框、未知前景障碍和安全膨胀区域搜索满足尺寸和净空要求的空位。
4. 放置推荐模块：输入待放置物品类别后，优先选择同类物品附近的安全空位；若没有同类锚点，则选择最大可用空位。

## 3. 实现要点

- GPU 优先：程序启动时检查 `torch.cuda.is_available()`，CUDA 可用时 Grounding DINO 在 GPU 上推理，并启用半精度推理；否则给出提示并降级 CPU。
- 开放词汇约束：主检测器使用 Grounding DINO，不使用 YOLO/SSD 等闭集检测器。
- 未知障碍保留：不属于四类但能被开放词汇提示词命中的物体会以 `semantic_unknown:*` 形式作为障碍参与空位避障；语义漏检时，再使用深度/颜色前景聚类兜底，不强行归入四类。
- 低置信候选降级：若 Grounding DINO 候选属于四类提示词但未达到该类阈值，只要仍高于未知阈值，就降级为语义未知障碍，而不是直接丢弃。
- 近中心去重：检测后处理不再把多个候选框取并集生成大框，只在中心点足够接近时视为同一物体，并优先保留已知类别或更紧的原始框。
- 鲁棒深度处理：支持多帧深度中值融合，并对无效深度孔洞进行局部中值补洞，降低 RealSense 深度噪声对空位定位的影响。
- 俯视/斜视适配：柜体 ROI 支持多边形遮罩，空位和三维点云只在遮罩内计算；层分割默认按 ROI 稳定等分三层，也支持手工配置不等高层边界。
- 单层约束：每个物体检测框必须落在单一层内，跨层大框直接舍弃，避免不同层物体被错误合并。
- 占用投影：每个已知物体和未知障碍在所属层内投影为整列占用矩形，空位由“层矩形减去占用矩形”得到，避免物体位置仍被标为空。
- 最终一致性约束：实时稳定器恢复短时漏检物体后，系统会再次用最终物体/障碍列表切分空位，保证可视化蓝框不与已显示物体重叠。
- 完整场景可视化：输出图保留柜子及周围环境，绿色框表示物品，红色框表示层板区域，蓝色框表示可用空位。
- 坐标单位：结果 JSON 和终端输出均给出以相机坐标系为基准的 `(X, Y, Z)` 三维坐标，显示时换算为毫米。

## 4. 运行方式

```bash
bash scripts/setup_env.sh
bash scripts/check_env.sh
bash scripts/run_live.sh
```

采集一帧数据：

```bash
bash scripts/run_capture.sh data/sessions/cabinet_01 --process-after-capture
```

离线回放：

```bash
bash scripts/run_replay.sh data/sessions/cabinet_01
```

无相机时可生成演示 session：

```bash
conda activate rs_exp5
python -m exp5 --mode demo --session data/sessions/demo
bash scripts/run_replay.sh data/sessions/demo --detector replay
```

## 5. 实验结果记录

实验运行后主要输出如下：

- `outputs/latest/annotated.png`：可视化结果图。
- `outputs/latest/result.json`：物品、层板、空位、障碍物和推荐位置的结构化结果。

结果示例应包含：

- 识别到的已有物品类别、置信度和 2D 框。
- 各物品底面接触中心的三维坐标。
- 每层柜子区域的红色框和层级编号。
- 满足尺寸/净空条件的空位蓝色框及中心 3D 坐标。
- 新物品类别对应的推荐放置层号和坐标。

## 6. 拓展内容

1. 推荐放置策略：系统不仅检测空位，还根据新物品类别寻找同类物品附近的安全空位，输出机械臂可用的放置锚点。
2. 信息化可视化面板：在完整场景图右侧显示类别统计、FPS、物品坐标表、空位坐标表和推荐结果。
3. 鲁棒性增强：实现多帧深度中值融合、深度补洞、有效深度过滤、深度前景聚类、障碍物安全膨胀、离线 replay 复现实验和无 CUDA 降级运行。

## 7. 结论

本系统完成了实验五要求的 RGB-D 数据采集、开放词汇物品类别识别、柜层识别、空位检测和三维定位输出。相比仅使用 RGB 图像的二维检测方法，RGB-D 方案能够给出真实世界坐标和空间占用信息，更适合服务机器人后续机械臂取放任务。
